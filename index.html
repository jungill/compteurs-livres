Synchronisation

Le plateau est publié dans un fichier plateau.json de ton dépôt GitHub. La lecture est libre ; publier demande un jeton d'accès, à créer dans Settings › Developer settings › Personal access tokens › Fine-grained, limité à ce seul dépôt, avec la permission Contents : Read and write.

Le jeton reste sur cet appareil et n'est jamais écrit dans le fichier publié. À saisir une fois par appareil.
